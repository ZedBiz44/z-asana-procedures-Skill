# Zed Asana Procedures

ZedBiz's main skill for clear routine Asana projects, tasks, and subtasks. Build the whole assignment unassigned, verify it, then assign it last.

Install only the `z-asana-procedures` directory in the agent's approved workspace skills root. Keep its references and assets together. The existing ZedBiz Asana access-control and communication skills remain required.

## What this release provides

The core procedure routes to short local references for projects, tasks/subtasks, fields/rules/templates, and delivery. Brief formats support clear descriptions while the actual Asana template library develops. This package does not create live Asana templates, install a connector, or enforce permissions at the server level.

The assignment gate is mandatory agent instruction, not executable enforcement. Live Asana setup remains subject to approved tools, verified identity, authority, and read-back. Specialized venture implementation is outside this release.
